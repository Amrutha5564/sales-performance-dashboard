### 🎯 Project Objective
To build a dynamic business intelligence dashboard that helps stakeholders track sales performance, profitability, regional growth, and product trends - moving beyond static Excel reports to an interactive web app.

### 📌 Key KPIs & Features Implemented

**KPIs Calculated:**
- 💰 **Total Sales & Total Profit** - Real-time aggregation
- 🧾 **Total Orders & Units Sold** - Volume metrics
- 🎯 **Profit Margin %** = (Profit / Sales) * 100
- 💵 **Avg Order Value** = Total Sales / Total Orders

**Interactive Visuals:**
1.  **📅 Monthly Sales Trend** - Line chart with seasonality detection
2.  **🌎 Sales by Region** - Bar chart for geographical performance
3.  **🛍️ Product Performance** - Horizontal bar chart with profit tooltip
4.  **🧩 Revenue Share by Category** - Donut chart (Pie)
5.  **💹 Profit by Region & Category** - Grouped bar comparison
6.  **🏆 Top 5 Products** - Data table with formatting
7.  **📄 Raw Data Viewer** - Expandable filtered dataset

**Smart Filters (Sidebar):**
- Region, Category, Product Multi-Select
- Dynamic Date Range Picker
- File Uploader for any Excel sheet named `SalesData`

### 🛠️ Tech Stack & Libraries
- **Frontend & App:** `Streamlit` - For interactive web UI
- **Data Manipulation:** `Pandas` - Data cleaning, type conversion, aggregation
- **Visualization:** `Plotly Express` - Interactive, responsive charts
- **Data Source:** `Excel (.xlsx)` - Sheet: `SalesData`
- **Language:** Python
